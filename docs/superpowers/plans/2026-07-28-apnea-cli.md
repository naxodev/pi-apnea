# Apnea CLI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship an `apnea` CLI so any agent that can run a shell command can drive an Apnea run, while the Pi plugin survives as a thin shim over the same definitions.

**Architecture:** A new `extension/registry.ts` becomes the single definition of every operation (Pi tool name, CLI verb, Typebox params, handler). `extension/index.ts`, `extension/adapters/commands.ts`, and a new `extension/cli/` all generate their surface from it. Separately, `workflow_wait` becomes resumable by moving its deadline and recovery-ladder state out of process memory and into `state.json`.

**Tech Stack:** TypeScript 7, Effect v4 (beta.101), Typebox, Bun (runtime, test runner, bundler), jj for version control.

**Design doc:** [`docs/superpowers/specs/2026-07-28-apnea-cli-design.md`](../specs/2026-07-28-apnea-cli-design.md)

## Global Constraints

- **Effect v4 idioms only.** Tagged errors from `extension/errors.ts`, no `throw` for control flow, services via `Context`/`Layer`. See [ADR 0008](../../adr/0008-effect-v4-internals.md).
- **No new dependencies.** `effect` and `typebox` are the only runtime deps and stay that way.
- **Tabs for indentation**, double-quoted strings — match surrounding files.
- **Imports use explicit `.ts` extensions** (`allowImportingTsExtensions` is on).
- **Time comes from Effect's `Clock`**, never `Date.now()` — `services/herdr.ts` was already fixed for this and tests use `TestClock`.
- **`workflows/`, `services/`, `domain/`, `schema/` must not import `@earendil-works/pi-coding-agent`.** That import is confined to `extension/index.ts` and `extension/adapters/commands.ts`.
- **VCS is jj** (colocated with git). Use `jj describe -m "..."` then `jj new`. Never `git add`/`git commit`.
- **Commit messages:** Conventional Commits, e.g. `feat(cli): …`. No AI attribution trailers.
- **Verification before any task is done:** `bunx tsc --noEmit` and `bun test` must both pass.

Create `extension/domain/timeouts.ts`:

```ts
import type { DispatchKind } from "./state-machine.ts";

/** Dispatch kind → the `timeouts_ms` key documented in docs/protocol/config.md. */
const STEP_KEY: Record<DispatchKind, string | null> = {
	plan: "planning",
	plan_review: "plan_review",
	phase_package: "phase_packaging",
	code: "coding",
	code_review: "code_review",
	// No dedicated key documented; PR description is short and uses default.
	pr_description: null,
};

export const DEFAULT_TIMEOUT_MS = 900_000;

export function timeoutMsForKind(
	kind: DispatchKind,
	timeouts: Record<string, number>,
): number {
	const key = STEP_KEY[kind];
	const specific = key ? timeouts[key] : undefined;
	return specific ?? timeouts.default ?? DEFAULT_TIMEOUT_MS;
}
```

```ts
import { toolToVerb } from "../registry.ts";
import type { ToolResult } from "../result.ts";

/** 0 ready · 1 refusal/error · 2 usage · 3 wait budget spent, call again. */
export const EXIT_OK = 0;
export const EXIT_ERROR = 1;
export const EXIT_USAGE = 2;
export const EXIT_PENDING = 3;

export function exitCodeFor(r: ToolResult): number {
	if (!r.ok) return EXIT_ERROR;
	return r.data?.pending === true ? EXIT_PENDING : EXIT_OK;
}

/** Canonical tool name → the command a shell caller actually runs. */
function asCommand(tool: string): string {
	const verb = toolToVerb(tool);
	return verb ? `apnea ${verb}` : tool;
}

export function renderHuman(r: ToolResult): string {
	const next = r.legal_next?.length
		? `\nnext: ${r.legal_next.map(asCommand).join(" | ")}`
		: "";
	const extra = r.data ? `\n${JSON.stringify(r.data, null, 2)}` : "";
	return r.ok
		? `OK: ${r.message}${next}${extra}`
		: `ERROR: ${r.error}${next}${extra}`;
}

export function renderJson(r: ToolResult): string {
	return JSON.stringify(r);
}
```

```ts
import { parseFlags } from "./parse.ts";
import { EXIT_USAGE, exitCodeFor, renderHuman, renderJson } from "./format.ts";
import { OPERATIONS, findByVerb } from "../registry.ts";
import { DISPATCH_KINDS } from "../domain/state-machine.ts";

function usage(): string {
	return [
		"apnea — multi-role workflow driver",
		"",
		"Usage: apnea <command> [args] [--json]",
		"",
		...OPERATIONS.map((o) => `  ${o.verb.padEnd(14)} ${o.summary}`),
		"  resume | abandon   actions on an existing run",
		"",
		`dispatch kinds: ${DISPATCH_KINDS.join(" | ")}`,
		"",
		"Exit codes: 0 ok · 1 refused/error · 2 usage · 3 still waiting (call again)",
	].join("\n");
}

export async function main(argv: string[]): Promise<number> {
	const [verbRaw, ...rest] = argv;
	if (!verbRaw || verbRaw === "help" || verbRaw === "--help") {
		console.log(usage());
		return verbRaw ? 0 : EXIT_USAGE;
	}

	// `resume` and `abandon` are actions on the start operation.
	const isAction = verbRaw === "resume" || verbRaw === "abandon";
	const op = findByVerb(isAction ? "start" : verbRaw);
	if (!op) {
		console.error(`unknown command: ${verbRaw}\n\n${usage()}`);
		return EXIT_USAGE;
	}

	const { flags, values, rest: positional } = parseFlags(rest);
	const json = flags.has("json");
	const params = buildParams(op.verb, isAction ? verbRaw : null, flags, values, positional);
	if (params === null) {
		console.error(`usage: apnea ${op.verb} …\n\n${usage()}`);
		return EXIT_USAGE;
	}

	const result = await op.run(params);
	const text = json ? renderJson(result) : renderHuman(result);
	if (result.ok) console.log(text);
	else console.error(text);
	return exitCodeFor(result);
}

if (import.meta.main) {
	process.exit(await main(process.argv.slice(2)));
}
```

Write `buildParams` in the same file. It mirrors the per-command parsing in `commands.ts`'s `switch (sub)` block so the CLI and `/apnea` accept identical arguments:

```ts
function buildParams(
	verb: string,
	action: string | null,
	flags: Set<string>,
	values: Map<string, string>,
	positional: string[],
): Record<string, unknown> | null {
	const num = (k: string): number | undefined => {
		const raw = values.get(k);
		if (raw === undefined) return undefined;
		const n = Number(raw);
		return Number.isFinite(n) ? n : undefined;
	};

	switch (verb) {
		case "start": {
			if (action) return { action };
			const goal = positional.join(" ").trim();
			if (!goal) return null;
			return {
				action: "start",
				goal,
				slug: values.get("slug"),
				allow_dirty: flags.has("allow-dirty") || undefined,
			};
		}
		case "dispatch": {
			const kind = positional[0];
			if (!kind || !DISPATCH_KINDS.includes(kind as never)) return null;
			return { kind, rework: flags.has("rework") || undefined };
		}
		case "wait":
			return {
				timeout_ms: num("timeout"),
				poll_ms: num("poll"),
				budget_ms: num("budget"),
			};
		case "commit": {
			const message = positional.join(" ").trim();
			return {
				message: message || undefined,
				no_remaining_phases: flags.has("done") || undefined,
			};
		}
```

```ts
export type HumanGateDeps = {
	isTty: () => boolean;
	prompt: (question: string) => Promise<string>;
};

export const prodHumanGateDeps: HumanGateDeps = {
	isTty: () => Boolean(process.stdin.isTTY && process.stdout.isTTY),
	prompt: async (question) => {
		process.stdout.write(question);
		for await (const line of console) return line.trim();
		return "";
	},
};

/**
 * Human-only confirmation for cap reset. An agent shelling out has captured
 * pipes, so the TTY check fails closed. `--i-am-human` remains available for
 * scripts and remote shells: the property this buys is auditability — the
 * bypass is named in the transcript — not prevention.
 */
export async function confirmHuman(
	gate: string,
	deps: HumanGateDeps,
	override: boolean,
): Promise<{ ok: true } | { ok: false; reason: string }> {
	if (override) return { ok: true };
	if (!deps.isTty()) {
		return {
			ok: false,
			reason:
				"reset-rounds is human-only and stdin/stdout are not a terminal. " +
				"Run it yourself in a shell, or pass --i-am-human to override.",
		};
	}
	const answer = await deps.prompt(`Type the gate key to confirm reset (${gate}): `);
	return answer === gate
		? { ok: true }
		: { ok: false, reason: `confirmation did not match "${gate}"; nothing reset` };
}
```

```markdown
# CLI driver: one registry, two front-ends
```
